git and GitHub

Version control

1. open GitHub.com
2. Sign Up to GitHub using gmail
3. Create Repository
4. Give name for repository
5. Few git commands will be displayed
6. We have execute these commands in
our local system using git
7. To initialize git repository
git init
8. To add any file to the repository 
git add <file name>
9. To add all the files to git repository
git add .
10 To commit the file
git commit -m "message"
11. to push to GitHub
git push
